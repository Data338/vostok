# Vostok — Obsidian theme

Tema **dark (OLED)** para Obsidian — irmão do tema Vostok do [opencode](https://opencode.ai) e do Neovim.

- Fundo OLED `#000`, acento escarlate `#ff3e3e`.
- Títulos em gradiente **vermelho → dourado → ciano**; **glow neon** opcional.
- Arestas retas (brutalista por padrão), paleta de código própria (Tron/keyword/string).
- Ajustável sem editar CSS via **Style Settings** (glow, raio das bordas, cor de acento).

## Instalação

1. Coloque esta pasta em `<vault>/.obsidian/themes/Vostok/` (o nome da pasta **precisa** ser `Vostok`).
2. Obsidian → **Settings → Appearance → Theme → Vostok**.
3. *(Opcional)* instale o plugin da comunidade **Style Settings** para expor os knobs.

## Arquivos

| arquivo | papel |
|---|---|
| `theme.css` | variáveis CSS + regras |
| `manifest.json` | metadados do tema |
